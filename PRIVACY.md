# Privacy

Visual Tab Manager stores its data locally in Firefox.

## What is stored locally

- domain selector rules
- UI settings such as theme, language, manager mode, and capture delay
- captured thumbnail previews for tabs

## What is transmitted

- Nothing by default.
- If the user explicitly grants optional access to all sites, the extension may read page content locally to create previews for the extension's primary function.
- The extension does not send browsing data, previews, selectors, or settings to any remote server.

## Third parties

- No analytics providers
- No ad networks
- No remote icon or favicon services
- No remote code execution

## User control

- Auto capture is off by default.
- Optional access to all sites can be granted or revoked from the extension settings and from Firefox's permission UI.
- Stored previews can be removed from the manager UI.
